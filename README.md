# اوژو (Uzhu): سایت ترک قند قدم به قدم

سایت ایستا (HTML/CSS/JS بدون نیاز به build)، فارسی و راست‌به‌چپ، قابل نصب روی گوشی (PWA).

## اجرا
هر وب‌سرور ایستایی کار می‌کند:
```
cd uzhu-site && python3 -m http.server 8080
```
سپس `http://localhost:8080` را باز کنید.

## فایل‌ها
- `index.html` و `css/style.css`: ساختار و ظاهر
- `js/app.js`: صفحه‌ها، برنامه‌ی روزانه، چک‌لیست شبانه، یادآورها، دکمه‌ی «هوس دارم»
- `js/program.js`: متن ۶۳ روز (۳ دوره‌ی ۲۱ روزه)، تمرین‌های هوس، جمله‌های انگیزشی
- `js/recipes.js`: دستورهای بی‌قند با تصویرهای کاریکاتوری (SVG)
- `js/articles.js`: مقاله‌های علمی و راهنمای قندهای پنهان
- `js/illustrations.js`: کاراکتر اوژو و تصویرهای سایت
- `js/store.js` و `js/config.js`: ذخیره‌ی حساب و پیشرفت
- `sw.js`: کار آفلاین و نمایش اعلان
- `research/`: بررسی رقبا و خلاصه‌ی پژوهش‌های پزشکی با منبع
- `supabase/schema.sql`: جدول‌های لازم برای ثبت‌نام آنلاین

## ثبت‌نام آنلاین با ایمیل
به‌طور پیش‌فرض حساب‌ها در مرورگر بازدیدکننده ذخیره می‌شوند. برای ثبت‌نام واقعی با ایمیل:
1. یک پروژه‌ی Supabase بسازید و `supabase/schema.sql` را در SQL editor اجرا کنید.
2. آدرس پروژه و publishable key را در `js/config.js` بگذارید.

## یادآورها
- وقتی سایت (یا نسخه‌ی نصب‌شده روی گوشی) باز است، یادآورها سر ساعت‌های انتخابی کاربر به‌صورت اعلان سیستمی و پیام داخل صفحه می‌آیند.
- برای یادآور وقتی سایت کاملاً بسته است، باید Web Push راه‌اندازی شود: کلیدهای VAPID، ذخیره‌ی اشتراک در جدول `uzhu_push` و یک تابع زمان‌بندی‌شده (Supabase Edge Function + cron) که پیام روز را می‌فرستد. `sw.js` آماده‌ی دریافت این پیام‌هاست.
